# Checklist de Sesión — Piloto AACES

**Fecha:** _
**Cliente:** _
**Duración:** _

## Pre-sesión

- [ ] Backend corriendo (`/health` → healthy)
- [ ] BD accesible
- [ ] Acceptance v1 pasa 18/18
- [ ] Versión del código registrada: `git log --oneline -1`

## Flujo principal

- [ ] Cliente inicia sesión
- [ ] Cliente crea un curso
- [ ] Cliente registra al menos 1 participante
- [ ] Cliente acredita al participante
- [ ] Cliente emite constancia
- [ ] Constancia tiene folio visible
- [ ] Constancia tiene código de validación
- [ ] Cliente descarga PDF de constancia
- [ ] Verificación pública del código funciona
- [ ] Cliente cancela constancia
- [ ] Verificación pública refleja cancelación
- [ ] Cliente re-emite constancia
- [ ] Timeline muestra emitido → cancelado → reemitido

## Reportes

- [ ] Reporte de constancias por período funciona
- [ ] Reporte de documentos no verificados funciona
- [ ] Dashboard muestra datos

## Post-sesión

- [ ] Feedback registrado en `feedback-template.md`
- [ ] Issues documentados (si aplica)
- [ ] Bitácora de acceptance guardada
