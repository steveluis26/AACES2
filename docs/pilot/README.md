# Pilot Program — AACES v0.9

## Objetivo

Validar el flujo completo del sistema con una organización real. No se busca escalar, sino observar cómo un usuario real interactúa con el sistema, detectar fricciones y recolectar evidencia para v1.0.

## Participante

Un (1) cliente piloto. No más.

## Duración

2-4 semanas.

## Entregables del piloto

1. Checklist de sesión completado (`checklist.md`)
2. Feedback documentado (`feedback-template.md`)
3. Issues reportados (bugs, dudas, sugerencias)

## Reglas

- El piloto no requiere nuevas funcionalidades
- Si algo no funciona, se documenta como bug, no se agrega como feature
- El roadmap no cambia durante el piloto
- Toda comunicación queda registrada
